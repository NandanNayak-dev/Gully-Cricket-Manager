# Gully Cricket Manager

A full-stack application for managing gully cricket matches, teams, and players.

## Prerequisites
- Node.js installed
- MongoDB installed and running locally on port 27017

## How to Run the Project

You will need to open **two** separate terminal windows to run both the frontend and backend simultaneously.

### 1. Run the Backend (API Server)
Open your first terminal and run the following commands:
```powershell
cd backend
npm start
```
The backend server will start running on `http://localhost:5000`.

### 2. Run the Frontend (React App)
Open a second terminal window and run:
```powershell
cd frontend
npm run dev
```
The frontend development server will start and you can view the application in your browser at `http://localhost:5173`.
